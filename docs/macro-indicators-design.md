# 한·미 거시경제 지표 수집·분석 설계서

- 상태: **신규 기능 설계 / 미구현**
- 최종 정리: 2026-11-13
- 적용 저장소: `bluehawhy/stock-briefing`
- 목적: **한국·미국 금리와 물가를 개별 수집**하고, 국제유가·원/달러 환율을 공통 지표로 결합해 국내 주식 아침 브리핑에 **설명 가능한 거시경제 해설**을 추가한다.
- 관련 연구: [공포탐욕지수와 금리·물가 영상 요약](research/fear-greed-2026-video-summary.md), [사용자 제공 영상 전사](research/fear-greed-2026-video-transcript.md)
- 변경 경계: 본 문서는 구현 계획이다. 기존 종목별 매수·매도 점수, 추천 수량, 예산, 주문 정책 및 08:30 발송 동작을 바꾸지 않는다.

## 1. 설계 결론과 분석 원칙

1. **금리**: 현재 수준뿐 아니라 *최근 변화, 향후 추가 인상/인하 압력*을 구분한다. 시장금리는 정책금리의 대체값으로 취급하지 않는다.
2. **물가**: 한국과 미국의 헤드라인·근원 CPI를 별도로 저장하고, 전년동월비(YoY)와 전월비(MoM)의 차이를 명시한다. 추세를 한 달 수치만으로 단정하지 않는다.
3. **유가**: WTI와 브렌트를 국제 공통 지표로 수집한다. 급등은 물가 압력, 급락은 경기 둔화 가능성도 있으므로 **등락 방향만으로 호재·악재를 판정하지 않는다**.
4. **환율**: 원/달러(원/1달러)를 수집해 한·미 금리 차이 및 국내 증시의 외국인 수급과 함께 해설한다. 금리 차이만으로 환율 방향을 예측하지 않는다.
5. **시장 심리**: CNN 공포탐욕지수는 참고 대상으로만 두고, 단독 매수 신호로 사용하지 않는다. 초기 수집 필수 범위에서는 제외한다.

분석 결과는 통계 수치 → 방향 → 근거 → 반대 신호 → 불확실성 순서로 표시하며, **투자 의견·자동 주문에 직접 연결하지 않는다**. 영상의 39회·76%·86% 등은 재현 검증되지 않은 외부 주장으로, 전략 임계값으로 채택하지 않는다.

## 2. 수집 대상 및 공급자

### 2.1 한국 🇰🇷

| 분류 | 수집 항목 | 기본 공급자 | 주기 | 비고 |
|---|---|---|---|---|
| 정책금리 | 한국은행 기준금리 | 한국은행 ECOS | 결정·변경 시, 일별 조회 가능 | 통계표 후보 `722Y001`; 항목·주기 공식 메타데이터 검증 후 확정 |
| 시장금리 | 국고채 3년·10년 금리 | 한국은행 ECOS | 영업일 | 통계표·세부항목 코드는 실제 제공 목록에서 확인 |
| 헤드라인 물가 | 소비자물가지수(CPI), YoY, MoM | KOSIS 소비자물가조사 | 매월 | 전년/전월 비교의 지수 기준과 계절조정 여부 보존 |
| 근원물가 | 식료품 및 에너지 제외 CPI | KOSIS 소비자물가조사 | 매월 | 농산물 및 석유류 제외와 **다른** 정의; 혼용 금지 |

- 한국 경제지표의 공식 수집 우선순위: **ECOS(금리)**, **KOSIS(물가)**.
- CPI 통계표 ID·분류코드·항목코드는 KOSIS에서 최신 목록을 조회하고 명시적으로 선택한다. 예전 통계표나 구 기준연도 시계열을 단순 연결하지 않는다.
- 한국 기준금리의 이벤트 발표 시각을 API에서 확인할 수 없다면 `미확인`으로 보존하며, 조회 시각을 발표 시각으로 위장하지 않는다.

### 2.2 미국 🇺🇸

| 분류 | 수집 항목 | FRED 시계열 | 주기 | 비고 |
|---|---|---|---|---|
| 정책금리 | 연방기금금리 목표 범위 하한 | `DFEDTARL` | 일별 유효값 | 범위의 하한 |
| 정책금리 | 연방기금금리 목표 범위 상한 | `DFEDTARU` | 일별 유효값 | 범위의 상한 |
| 시장금리 | 미 국채 2년·10년 수익률 | `DGS2`, `DGS10` | 영업일 | 정책금리와 별도 표시 |
| 헤드라인 CPI | 미 CPI 원지수(비계절조정) | `CPIAUCNS` | 매월 | YoY 계산 및 양국 물가 비교 시 활용 |
| 헤드라인 CPI | 미 CPI 계절조정 지수 | `CPIAUCSL` | 매월 | MoM 추세에 활용 |
| 근원 CPI | 식료품·에너지 제외 계절조정 지수 | `CPILFESL` | 매월 | 기본적으로 MoM 추세용 |

- 미국 물가의 최초 공표 출처는 BLS이고, 수집 채널은 FRED로 통일한다.
- 한국 CPI와 미국 CPI는 조사 대상·품목 가중치 등이 다르다. **같은 월·같은 YoY 정의로 비교하되 완전히 동질적이라고 해석하지 않는다.**
- 정책금리 목표 구간(`DFEDTARL~DFEDTARU`)과 실효 연방기금금리(`FEDFUNDS`/일별 `DFF`)는 서로 다른 개념이다. 필요 시 실효금리를 보조로 수집하되 목표 범위를 대체하지 않는다.
- CPI 원지수의 단순 MoM은 계절성이 있으므로, 미국 월간 물가 모멘텀은 계절조정 지수를 사용한다.

### 2.3 국제유가·환율 🌍

| 분류 | 수집 항목 | 기본 공급자 | 코드·후보 | 단위/시각 |
|---|---|---|---|---|
| 국제유가 | WTI 현물 | FRED(원천 EIA) | `DCOILWTICO` | USD/배럴, 일별 |
| 국제유가 | 브렌트 현물 | FRED(원천 EIA) | `DCOILBRENTEU` | USD/배럴, 일별 |
| 환율 | 원/달러 환율 | 한국은행 ECOS | `731Y003` 후보, 항목 확인 필요 | KRW/1 USD, 일별 |
| 환율 보조 | 원/달러 현물 환율 | FRED(원천 연준 H.10) | `DEXKOUS` | KRW/1 USD, 일별 |

- ECOS 환율을 **주값**으로 쓰고, FRED 환율은 대조·장애 시 *보조 출처*로 둔다. 두 기관의 고시·관측 시각이 다르므로 값을 섞거나 무조건 하나로 덮어쓰지 않는다.
- 국제유가는 두 국가에 **공통 시계열 하나씩** 저장하며 국가별로 중복 수집하지 않는다.
- 현물 유가는 실시간 선물 가격이 아니다. 영업일·공휴일·시차·게시 지연을 고려하고, 전 거래일 관측값에 당일 시세라는 표시를 하지 않는다.

## 3. 수집·저장 설계

### 3.1 독립적인 데이터 공급자 계층

```text
한국은행 ECOS ─┐
KOSIS ─────────┤
FRED ──────────┼─> macro provider adapter ─> 정규화/검증 ─> PostgreSQL
              │                                      │
              └──── 별도 발표 일정·정정 확인 <────────┘
                                                       │
                                        국가별 분석 + 공통 유가/환율
                                                       │
                                        시장 해설 스냅샷 저장
                                                       │
                         기존 08:30 텔레그램 / 요청 브리핑에 추가
```

- 요청을 계열·관측일 기준으로 증분 수집한다. 서버 재시작과 중복 요청은 같은 저장 상태를 재활용한다.
- **월간 CPI는 데이터가 공개된 뒤에만** 갱신한다. 휴일·발표 지연을 누락 오류로 오판하지 않는다.
- 일별 금리·원유·환율은 각 제공자가 마지막으로 공개한 관측일까지만 적재한다. FRED의 결측값 `.` 등은 숫자 0으로 바꾸지 않는다.
- 일일 브리핑 시각 08:30 KST는 **해외 자료가 모두 갱신되는 시각이 아니다**. 해당 시점에 실제 확인 가능한 가장 최근 발표치만 사용하고 기준일·수집 시각을 표시한다.
- API 제한·429·5xx 시 공급자별 제한된 재시도와 백오프를 적용하고, 실패한 계열만 재수집한다. 한 공급자 장애가 전체 브리핑을 막지 않도록 신규 거시 해설만 `확인 필요`로 처리한다.
- 초기 인증 키 설정 이름 예시: `ECOS_API_KEY`, `KOSIS_API_KEY`, `FRED_API_KEY`. 실제 구현 시 기존 환경설정 체계에 맞춰 결정한다. URL·헤더·로그에 포함될 수 있는 키와 원문 요청을 기록하지 않는다.

### 3.2 PostgreSQL 모델(안)

```text
macro_series
  series_id(PK), country(KR/US/GLOBAL), indicator
  provider, provider_series_id, unit, frequency
  seasonal_adjustment, description, is_active

macro_observations
  series_id(FK), observation_date, value
  source_updated_at(nullable), fetched_at
  PRIMARY KEY (series_id, observation_date)

macro_release_log
  series_id, period, published_at(nullable)
  detected_at, provider, status, revision_note

macro_briefing_snapshots
  briefing_date, generated_at, classification_version
  used_series_and_observation_dates(JSON), narrative(JSON)
  quality_status, missing_fields
```

- 관측일(`observation_date`), 발표일(`published_at`), 수집일(`fetched_at`)은 **서로 다른 필드**다. 발표시각 미제공 시 NULL을 허용한다.
- 공식 정정값은 `macro_observations`에 최신값으로 upsert하되 변경 내역/구값을 별도 수정 이력으로 보존한다. 과거 브리핑 스냅샷은 생성 당시 사용한 수치와 출처를 고정하여 사후 변경으로 내용이 달라지지 않게 한다.
- 과거 경제지표를 사용한 재현 실험에는 당시 발표된 **실시간 빈티지(vintage)** 기록이나 발표시점별 스냅샷이 필요하다. 현재 수정된 최종값을 과거에도 알고 있었다고 가정하는 분석은 금지한다.
- 금리·CPI는 % 또는 지수, 유가는 USD/배럴, 환율은 KRW/USD로 분리 저장한다. 통화·퍼센트·퍼센트포인트를 혼합 계산하지 않는다.

### 3.3 계산 및 품질 규칙

| 산출값 | 계산 | 주의 |
|---|---|---|
| CPI 전년동월비 | `(이번 월 지수 / 12개월 전 지수 - 1) × 100` | 동일한 통계 계열·기준 적용. 기준연도 개편·시계열 단절 확인 |
| CPI 전월비 | `(이번 월 계절조정 지수 / 전월 지수 - 1) × 100` | 계절조정된 동일 계열끼리만 비교 |
| 최근 물가 추세 | 최근 발표 3개월·6개월의 YoY/SA MoM 변화 | 추세 분류 임계값은 검증 후 결정; 현재 설계에서 고정하지 않음 |
| 한미 정책금리 차이 | `한국 기준금리 - 미국 목표금리 하한/상한`을 **범위로** 계산 | 미국 상한 하나를 전체 기준금리로 표현하지 않음; 정해진 중간값을 쓰려면 명시 |
| 한미 장기금리 격차 | 한국 10년 국고채 수익률 - 미국 10년 국채 수익률 | 같은 관측일만 비교, 발행/시장 정의 차이 별도 주석 |
| 유가 변화율 | 최근 비교 가능 관측일 기준 7일·30일·90일 수익률 | 달력일/영업일 정의 및 원인 미확인 표시 |
| 환율 변화율 | 동일 공급원 기준 1일·7일·30일 변동률 | KRW/1 USD **상승은 원화 약세** |
| 시장 스트레스 | CPI 둔화·가속, 정책금리 변화 및 유가/환율 위험을 개별 서술 | 추정 인과관계를 사실로 확정하지 않음 |

- 전월 대비 비교는 월 데이터에서 같은 계열로 계산하고, `YoY`를 한 달 변동과 혼동하지 않는다.
- 국채금리·환율·유가는 장 마감/고시 기준이 다를 수 있으므로 정확한 일치 시점이 없으면 서로 다른 날짜임을 함께 표시한다.
- `정상 / 미발표 / 수집 지연 / 공급자 오류 / 시계열 중단 / 검증 불가`를 구분한다. 이전 관측치 사용 시 반드시 **관측일**을 노출한다.

## 4. 시장 국면 해설

### 4.1 국가별로 먼저 해석

**한국**: 한국은행 정책 방향, 국고채 금리, 한국 CPI·근원 CPI 추세를 함께 본다. 원/달러와 외국인 수급은 별도 연관 지표로 설명한다.

**미국**: FOMC 목표 범위, 미 국채금리, 미국 CPI·근원 CPI의 가속/둔화 여부를 함께 본다. 한국과 비교할 때는 같은 기간·같은 단위로 정규화한다.

**공통**: WTI/브렌트와 원/달러의 변화가 물가 부담, 성장 및 외국인 투자 환경에 어떻게 작용할 수 있는지 **조건부로** 설명한다.

### 4.2 참고용 다섯 가지 국면(영상의 분석 틀)

| 참고 국면 | 관찰 조건의 예 | 브리핑 해설 방향 |
|---|---|---|
| A. 낮은 금리·안정 물가 | 정책금리 낮음 + CPI 압력 제한적 | 긴축 여유가 크지 않으면 충격의 지속성 점검 |
| B. 금리 인상·안정 물가 | 인상 진행 + 물가 가속 미약 | 인상 속도 조정 가능성 점검 |
| C. 금리 인상 종료 근접·물가 둔화 | 최근 인상 둔화 + CPI 하락 추세 | 긴축 압력 감소 가능성 점검 |
| D. 금리 인하 국면 | 정책금리 인하 진행 | 경기 악화에 따른 인하인지 함께 판단 |
| E. 높은 물가·추가 긴축 우려 | 물가 재가속 + 인상 여지 | 단기 반등 후 재하락 위험도 함께 설명 |

이는 **외부 영상의 서술을 체계화한 참고 체계**이지 통계적으로 검증된 판정 알고리즘이 아니다. A~E는 정의가 겹칠 수 있으므로 실서비스에서 자동 분류하려면 정량 임계값·우선순위·독립 백테스트·실시간 빈티지 검증이 선행되어야 한다. 구현 초기에는 **국면 레이블 대신 근거별 설명**을 기본으로 한다.

### 4.3 유가와 환율의 보조 해석

- 유가 **공급 충격 상승**: 기대 인플레이션 및 생산 비용 확대 가능성.
- 유가 **수요 감소 하락**: 물가 하락과 동시에 성장 둔화 신호일 수 있음.
- 유가 급변 원인을 확인하지 못하면 `원인 미확인`; 유가의 방향만 보고 매매 신호를 생성하지 않는다.
- 원/달러 상승은 원화 약세로, 수입 물가 부담을 높일 수 있다. 하지만 수출 실적·외국인 매매·환헤지 등의 영향은 종목마다 달라 일괄 매수/매도 점수로 환산하지 않는다.

## 5. 브리핑에 표시할 내용

기존 종목별 브리핑 앞에 **[한·미 거시경제]** 절을 추가하는 설계다. 아래 숫자는 예시가 아니라 **서식 템플릿**이며 실제 값이 저장되기 전까지 수치를 출력하지 않는다.

```text
[한·미 거시경제] (발송 YYYY-MM-DD 08:30 KST)

🇰🇷 한국
- 기준금리: [값]% (적용일 YYYY-MM-DD, 최근 방향)
- 국고채 3년 / 10년: [값]% / [값]% (관측일)
- CPI YoY / 근원 CPI YoY: [값]% / [값]% (YYYY-MM 기준)
- 해설: 물가 상승압력 [둔화/지속/가속/판단 보류]

🇺🇸 미국
- 연준 목표금리: [하한]~[상한]% (적용일)
- 미 국채 2년 / 10년: [값]% / [값]% (관측일)
- CPI YoY / 근원 CPI: [값]% / [값]% (YYYY-MM 기준)
- 해설: 추가 긴축 압력 [축소/유지/확대/판단 보류]

🌍 국제유가·환율
- WTI / Brent: [값] / [값] USD/배럴 (관측일)
- 원/달러: [값] KRW/1 USD (관측일)
- 유가 변화 원인: [확인된 원인/미확인]

한·미 비교
- 정책금리 차이: 한국 - 미국 목표금리 범위 [값]~[값]%p
- 물가 추세: [한국] / [미국] (서로 다른 기준월이면 비교 보류)
- 종합 해설: [금리, 물가, 유가, 환율을 연결한 조건부 설명]
- 경계/불확실성: [미발표·결측·시차·통계 정의 차이]
```

- 매일 08:30에는 최신 *관측 가능한 공식 자료*로 작성하고, 데이터 공표 전이라면 이전 확정치를 **그대로** 표시하며 기준일을 숨기지 않는다.
- 데이터 공급 장애 시 해당 항목만 `데이터 확인 필요`로 표시하고 유효값 없는 경제 분석이나 점수는 만들지 않는다.
- 기존 `오늘 브리핑`/정기 텔레그램 발송은 같은 설명 스냅샷을 참조하되, 기존의 권한·중복 발송 방지·발송 이력 정책을 유지한다.
- 대시보드에 추가할 경우 한국/미국 개별 카드, 3·6·12개월 비교 차트, 원자료 기준일·출처·수집 오류를 표시한다. **화면 구현은 별도 작업**이다.

## 6. 단계별 도입 및 수용 기준

### 1단계 — 데이터 수집/검증 (구현 예정)

- ECOS·KOSIS·FRED API의 이용 가능 여부, 키 발급, 요청 제한, 통계표/항목 코드를 실제 응답으로 확인한다.
- 한국/미국 정책금리·국채금리·헤드라인/근원 CPI, 공통 WTI·브렌트 및 원/달러를 수집한다.
- 발표 전 값 제외, 결측·휴장·지연·정정/수정 이력 기록, 기준시각 보존을 확인한다.
- 수집 실패 시 기존 주식 브리핑 발송은 유지하고 거시 절만 보류한다.

### 2단계 — 설명형 분석과 출력 (구현 예정)

- 국가별 금리·물가 흐름, 정책금리 격차, 유가·환율 변화를 해설한다.
- 매일 08:30 텔레그램 및 요청 브리핑에 별도 섹션으로 표시하고 출처·기준일을 포함한다.
- 숫자·서술 간 모순/기준월 불일치/인과관계 과장에 대해 검증 절차를 마련한다.

### 3단계 — 정량화 여부 별도 결정 (미결정)

- 기존 영상의 공포 구간·5개 국면을 **검증 가능한 출처와 방법론으로** 재구성한 뒤 과거 구간·실시간 빈티지 자료로 분석한다.
- 보유·관심종목의 매매 점수에 거시 요인을 반영할지 별도 요구사항으로 승인받는다. 승인 전에는 매매 점수, 제안 수량, 예산, 주문 로직과 **독립 유지**한다.

## 7. 결정 사항 / 미확정 사항

**결정:** 한국·미국 금리와 CPI를 각각 수집한다. 유가는 WTI/브렌트 글로벌 공통으로, 환율은 원/달러로 수집한다. ECOS/KOSIS/FRED를 우선하고 기존 텔레그램 브리핑에 설명형 섹션을 붙인다.

**미확정:** 세부 통계표 항목 ID의 실제 API 검증, 일별/월별 수집 빈도 최종값, 최신성 허용 시간, 국면 판정 임계값, 시장 해설의 자동화 수준, 추가 데이터 비용·이용조건. 확인되지 않은 것은 `미확인`으로 표시하며 임의 숫자로 운영 기본값을 만들지 않는다.
